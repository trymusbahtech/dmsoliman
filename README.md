# Dr. Mohamed Mostafa Soliman — Portfolio Website

A bilingual Arabic/English portfolio and professional website for Dr. Mohamed Mostafa Soliman, Consultant of Diagnostic and Interventional Radiology.

## Pages

- Professional profile and qualifications
- Clinical radiology and ultrasound expertise
- Smart Scan services
- RadioMind medical training
- Patient education articles
- Video library and scientific events
- Contact and WhatsApp enquiry pathways

The Arabic edition is served from the project root. The full English edition is available under `/en/`.

## Local development

The project is a buildless static website. Serve the directory with any local HTTP server; in the current Laragon setup it is available at:

```text
http://localhost/dmsoliman/
```
